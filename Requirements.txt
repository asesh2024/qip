Environment Setup & Dependency Installation
===========================================
To ensure full reproducibility of the experimental pipeline, models, and figure generation routines, set up an isolated Python environment and install the required packages.

1. Create a Virtual Environment

On Linux / Ubuntu (WSL2):

Bash
python3 -m venv venv
source venv/bin/activate
On Windows (Command Prompt / PowerShell):

DOS
python -m venv venv
venv\Scripts\activate
2. Upgrade Pip & Install Dependencies

Upgrade pip to the latest version and install the pinned dependencies from requirements.txt:

Bash
pip install --upgrade pip
pip install -r requirements.txt

3. Dependency Overview

numpy>=1.26.0: Core numerical backend for matrix manipulations, vectorized continuous-to-discrete mappings, and probability density calculations.

pandas>=2.2.0: Dataframe structures for managing experimental splits, confusion matrix counts, calibration logs, and timing metrics.

scikit-learn>=1.5.0: Implementation of Random Forest classifiers, multi-class Platt scaling (CalibratedClassifierCV), and evaluation metrics (log loss, Brier score).

matplotlib>=3.8.0: High-resolution rendering engine for reliability diagrams, calibration curves, and runtime benchmark figures.

seaborn>=0.13.0: Statistical data visualization and confusion matrix heatmaps.

joblib>=1.4.0: Serialization and loading of trained machine learning model artifacts.

4. Verification

Verify the installation by checking package versions:

Bash
python -c "import numpy, pandas, sklearn, matplotlib, seaborn, joblib; print('Environment initialized successfully.')"
